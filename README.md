# DSA210 Project — What Makes a Movie Successful?
Data Science project for DSA210

## Data Sources
- TMDb Movies Dataset (tmdb_movies_csv.csv)
- Netflix Titles Dataset (netflix_titles_csv.csv)
- 
## How to Run
1. Open analysis.ipynb in Google Colab
2. Upload both CSV files to /content/
3. Run all cells in order

## Milestone 2 - EDA & Hypothesis Tests
- Data cleaning and feature engineering
- EDA: profit distribution, revenue by genre, budget vs revenue, ratings by decade
- Hypothesis tests: Pearson correlation, ANOVA, t-test
